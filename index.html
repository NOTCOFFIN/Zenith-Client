FAQ

Questions,
answered.

Is Zenith Client available yet?+

Not yet. This website is the first polished public-facing concept. The launcher and client still need to be built and tested.

Will Zenith support multiple Minecraft versions?+

That is a core goal: profiles for modern and legacy Java Edition versions, with version-specific loader and mod handling.

What is Zenith AI supposed to do?+

It is planned as a launcher assistant for tasks such as finding compatible trusted mods, explaining conflicts and helping configure profiles.

Is this Lunar Client or Feather Client?+

No. Zenith is an independent concept with its own branding and interface, inspired by the quality bar of modern Minecraft clients.
