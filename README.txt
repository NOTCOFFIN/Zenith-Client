ZENITH CLIENT WEBSITE

How to open:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox, or Safari.

Files:
- index.html     Main website
- styles.css     Full design + responsive animations
- script.js      Scroll reveal, 3D tilt, mobile navigation

To publish free:
- Upload this folder to Netlify Drop, Cloudflare Pages, GitHub Pages, or Vercel.

Note:
This is a website for the Zenith Client concept. The download buttons intentionally say Coming Soon because there is no finished launcher binary yet.
